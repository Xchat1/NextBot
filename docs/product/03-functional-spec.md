# NextBot 功能规格与验收

v0.1 评审稿 | 2026-11-27

[产品需求文档](01-prd.md) · [产品说明书](02-product-guide.md)

本文供产品、工程和测试评审。下列能力与用例均为拟建目标。P1 验证单人、私网 HTTPS、响应式 Web、单执行节点和 Codex CLI。P2 是首个发布版本，增加 Claude Code 执行适配、跨 Agent 交接和独立只读复核。P2 必须验证 Codex 执行、Claude Code 只读复核。反向组合在实测通过并列入支持清单后开放。多节点调度进入 P3。

## 1. 功能清单与验收场景

每个功能组对应一项用户能力。场景中的 P1、P2 表示首次要求通过的阶段。P2 继续覆盖 P1 的单节点和双端操作，并按 P2 复核规则验收交付。

| 编号与功能组 | 范围与行为 | 验收场景与预期结果 |
| --- | --- | --- |
| F01 自托管与数据恢复 | 所有者在私网 HTTPS 地址使用自托管控制服务。备份包含任务、尝试、授权记录、审计和归档产物。列出未纳入备份的节点工作目录及 Agent 凭据。 | **A01（P1）** 在无公共中继的私网打开服务。归档一项任务，重启后重新打开其历史和产物。生成备份并核对清单、文件个数及校验值。P2 的干净实例恢复见 A21。 |
| F02 身份/设备 | 一个所有者分别配对桌面和手机。配对凭据单次有效并有有效期。所有者可查看和撤销设备。 | **A02（P1）** 手机完成配对后，第二台设备复用该凭据或使用已过期凭据均被拒绝。桌面撤销手机后，手机既有连接和新请求均不能继续读取任务或提交决定，审计能识别被撤销的设备。 |
| F03 节点/适配器 | 记录节点连接、CLI 登录和适配能力，包括启动、取消、原生会话续接、读取产物及可强制的权限约束。模型凭据保留在执行节点。 | **A03（P1）** 一台配置好 Codex 的节点可接单。退出 CLI 登录或缺少任务要求的能力时，界面显示原因，任务不启动。**A04（P2）** 验证 Claude Code 执行适配器可完成同类任务，手机无需录入模型密钥。若其搭档未通过只读复核认证，用户选择该执行与复核组合时，服务端阻止启动并说明原因。 |
| F04 项目与工作区 | 项目绑定节点上的仓库及基准提交。每个写任务使用独立 Git worktree 和分支。保留任务归属、工作目录和基准版本。 | **A05（P1）** 从同一基准建立两个任务，其工作目录不同。第一个任务新增的文件在第二个任务及原工作目录中均不可见。取消后仍可查看已归档的证据。worktree 只提供工作文件隔离。 |
| F05 任务与调度 | 任务含目标、范围、验收条件及执行 Agent。提交后排队，单节点最多同时运行一个写执行。支持取消待执行任务。 | **A06（P1）** 连续提交 A、B，手机重发 B 的同一提交。只产生两项任务。A 占用写执行名额时 B 排队，取消 B 后，A 释放名额也不会启动 B。 |
| F06 Agent 执行/恢复 | 记录每次执行的尝试编号、Agent、原生会话标识（如可取得）、节点、起止与结果。原生续接和新开尝试在界面上可区分。 | **A07（P1）** 运行时断开浏览器，重连后看到同一次尝试。模拟 CLI 意外退出，原会话可续接时明确显示续接。无法确认执行结果时保留尝试并阻塞，核对进程与产物后才能决定下一步。 |
| F07 交接与复核 | 交接包绑定任务、基准提交、当前产物版本、执行摘要、已有证据及未决问题。不同于执行者的另一 Agent 在独立只读会话内给出结论与证据引用。 | **A08（P2）** 必测 Codex 执行、Claude Code 强制只读复核。拟开放反向组合时，再以同一套用例验证 Claude Code 执行、Codex 强制只读复核，通过后公布。复核可查阅差异与归档日志，不能改文件、执行任意仓库脚本或发布结果。缺测试证据时退回，由受管执行步骤补齐并生成新版本。 |
| F08 产物与验收 | 按版本归档差异、执行摘要、测试或验证记录。界面始终展示验收对应的版本、复核结论及证据。 | **A09（P1）** 所有者在手机查看当前版本并验收。**A10（P2）** 缺少当前版本的通过结论时，直接调用验收接口也被拒绝。验收通过后任务记为已完成，仓库默认分支及远端引用均无变化。 |
| F09 受管动作授权 | 受管动作必须经平台能够强制执行的适配器或受控执行边界。授权绑定尝试、动作、目标和参数摘要，并带有效期。 | **A11（P1）** 对预登记的一次测试运行分别演练允许、拒绝和超时。核查节点实际启动记录及次数，允许时一次，拒绝或过期时零次。让执行 Agent 在该受管环境中尝试通过其他终端或工具启动同一测试，也应被阻止。参数变化须重新授权，结果未知禁止重发。双端竞争见 A23。适配器不能强制门控而任务要求该保护时，提示不兼容并阻止启动。 |
| F10 跨端事件/待办 | 桌面与手机共用服务端任务时间线和待办。事件有可继续读取的位置，离线期间的决定以服务端结果为准。 | **A12（P1）** 手机离线时用桌面处理待办，手机重连后补齐历史，待办只消除一次，无新尝试。历史位置失效时加载当前快照与后续事件。手机在窄屏可独立查看差异、答复和验收。 |
| F11 审计/诊断与控制 | 按任务追溯提交、尝试、交接、授权、返工、取消和验收。记录操作者、设备、节点、时间、对象及结果。所有者可停止任务和导出脱敏诊断。 | **A13（P1）** 对运行中的任务发起取消。未获节点确认前展示取消请求进展，确认停止后才释放写名额。**A14（P2）** 从验收记录定位当时的产物、复核及所有者决定。用含模拟密钥的受管字段生成诊断，导出中无该值或配对凭据。 |

## 2. 任务状态与转换

任务承载目标和验收条件，尝试记录一次执行或复核，产物版本标识一次可供评审的交付。允许本次操作的授权只对单个受管动作生效。接受产物会关闭任务，退回则开启返工。

主状态描述任务进展。等待授权、等待答复、节点失联是独立的阻塞原因，可叠加，清除其中一项不会自动解除其他阻塞。每次转换记录原因和对应尝试。两台设备读取同一份服务端状态。

| 当前状态 | 条件和操作 | 下一状态与约束 |
| --- | --- | --- |
| 草稿 | 所有者填写任务并提交，或放弃 | 提交进入排队中。放弃进入已取消。 |
| 排队中 | 节点可用、所需能力齐全、取得唯一写名额 | 启动一个写执行后进入执行中。轮到前可取消。 |
| 执行中 | 当前执行结束且产物已归档 | P1 进入待验收。P2 进入待复核。写进程确认停止且归档完成后释放写名额，后续复核可以与其他工作树的写执行并行。只收到派发回执时不能将任务送审。已知可重试的故障经核实并决定新开尝试时，重新进入排队中。 |
| 待复核 | 独立复核 Agent 取得指定版本的只读交接包 | 进入复核中。复核服务暂不可用时保留待复核和原因。 |
| 复核中 | 当前版本复核通过，或需补充证据、修改产物 | 通过进入待验收。退回且未超限进入排队中，开启返工。复核结果必须标明引用的版本。复核进程若异常结束且未形成结论，核实旧进程已经停止后可回到待复核，在同一产物上新开复核尝试。 |
| 待验收 | 所有者接受当前版本，或说明退回理由 | 接受后进入已完成。退回且未超限进入排队中。P2 仅允许接受已通过独立复核的当前版本。 |
| 任一非终态 | 所有者取消，或遇到不可恢复的执行失败 | 未运行可直接取消。运行中的任务确认停止后进入已取消。确认失败且无法在本任务内继续时进入已失败。失联本身不触发终态。 |
| 已完成、已失败、已取消 | 回看历史或从失败、取消的任务重做 | 终态记录保留。重做创建关联原任务的新任务，独立排队。 |

**尝试与返工。** 一次任务可包含多次尝试。可恢复的失败经确认重试时保留旧尝试及失败原因，同一次尝试续接时继续沿用原编号。每次返工排队并生成新的执行尝试及新产物版本，历史版本与结论保留。P2 再次进入独立复核，旧版本的通过结论对新版本无效。

**返工上限。** 每项任务默认最多允许两轮返工，执行故障重试单独计数。第三次请求返工时显示已用轮数，保留当前主状态，标记等待答复并停止派发。所有者可另建关联任务或终止原任务。已有可验收的当前版本时仍可接受，P2 始终要求该版本复核通过。

## 3. 控制权限

| 主体 | 允许的动作 | 强制边界 |
| --- | --- | --- |
| 已配对的所有者设备 | 查看所属任务、提交、批准或拒绝受管动作、答复、返工、验收、取消 | 每次请求核验设备和对象。重复决定返回已经生效的结果，旧版本决定不能改变新版本。 |
| 执行 Agent | 在指定工作区按适配能力执行，提交结果，提出受管动作请求 | 模型密钥保留于节点。平台仅对实际能强制约束的动作提供审批保障。Agent 不能替所有者批准自己的动作或验收任务。 |
| 独立复核 Agent | 读取指定版本的产物和已归档证据，提交通过或退回结论 | 只读通道不授予仓库写入、任意脚本运行、外部发布或批准权限。不具备该约束时保持待复核。 |
| 控制服务及执行节点 | 持久化决定，核对任务与尝试，派发获准动作，返回实际结果 | 服务端回执表示决定已记录。节点回执与可核实证据用于认定外部动作是否发生。 |

## 4. 故障恢复与异常验收

| 编号与情形 | 预期结果 |
| --- | --- |
| **A15（P1）** 浏览器在提交后、收到回执前断网 | 用同一命令标识查询或重发，定位原任务。服务端不再入队。 |
| **A16（P1）** 节点在受管动作派发后、记录结果前失联 | 保留当前任务、尝试和写名额，标记节点失联。重连后核对进程、动作记录或产物。节点恢复连通且结果仍不明时，清除节点失联并标记等待答复，要求人工核实，禁止自动重放。命令去重不能保证外部动作恰好执行一次。 |
| **A17（P1）** 执行确认退出，适配器无法原生续接 | 显示最后确认位置和已归档证据。允许所有者从已知状态开启另一次尝试，保留旧尝试。若已进入终态则另建关联任务。 |
| **A18（P2）** 复核期间断线、返工后旧结论迟到 | 先核实复核尝试是否仍在进行。迟到结论只附于旧版本历史，当前版本必须有自己的通过结论。 |
| **A19（P2）** 两次返工后再次被要求补证 | 显示上限并停止继续派发，提供另建关联任务或终止选项。当前版本未通过复核时拒绝验收。 |
| **A20（P2）** 桌面请求验收旧版本，手机已退回该版 | 按当前任务状态和版本拒绝过期决定，刷新后两端看到同一返工尝试与操作者。 |
| **A21（P2）** 将一项已完成任务和一项中断任务的备份恢复到干净实例 | 校验清单后，逐项打开任务、决定、实际差异和证据内容。中断任务列出需要重连的工作区或会话，重连前不派发。恢复的备份不能使已撤销设备获得访问。 |
| **A22（P2）** 选择其他实例的备份，或删除备份中的一份差异文件 | 与目标实例不符时展示来源与目标，阻止覆盖。干净实例的所有者须核对待导入的来源。缺文件或校验失败时列出对象，终止导入，原数据仍可读取。 |
| **A23（P2）** 手机按批准的同时桌面按拒绝 | 每组仅一个有效决定，先提交成功的决定生效。拒绝先到时无派发，批准先到且条件有效时最多派发一次。两端均能查到结果及生效设备。 |
| **A24（P1）** 模型供应商离线，私网控制服务仍在线 | 两端仍可读已归档的任务、产物与决定。需要该供应商的新执行不能被标为成功，任务显示受阻或失败的具体原因与可用操作。 |
| **A25（P2）** 所有可信设备丢失 | 私网陌生设备无法自助认领实例。所有者在安装主机重新验证本机管理权限并绑定新设备，旧会话、未用配对凭据均失效，任务与历史决定完整可查。 |
| **A26（P2）** 用户有未提交文件，或任务工作树被人工修改 | 从明确选中的提交启动新任务，原目录中的已修改、未跟踪文件保持原样。若重试需覆盖被人工修改的任务工作树，先阻止覆盖并提示保留当前目录、另建工作树。 |
| **A27（P2）** 产物引用存在但归档缺失，或测试仅有 Agent 自述 | 读取失败明确指出缺失对象，复核和验收入口均阻止接受损坏版本。已完成任务保留当时的决定并标注证据当前不可读。缺少要求的测试记录时退回补证。 |
| **A28（P1）** Agent 询问输出格式，两台设备答复同一问题 | 答复关联问题和当前尝试，保留首个生效答复并显示来源。仅解除对应的“等待答复”。对已取消任务、旧尝试或过期问题的答复不交给新的执行者。 |
| **A29（P2）** 控制服务重启，执行节点与原进程仍在 | 服务恢复后用持久记录与节点核对原尝试。重启期间的结果只归档一次。手机重连后能看到已生效的决定和最终产物，节点没有重复启动 Agent。 |

## 5. 核心对象和最小记录

所有记录使用稳定标识。名称、设备昵称、当前分支名仅供显示。以下关联在提交、派发、归档和决定生效时校验，可据此从验收决定追溯到最初的基准提交。

| 对象 | 最少记录哪些信息 | 关联与唯一性 |
| --- | --- | --- |
| 所有者、设备 | 所有者标识、所属实例。设备标识、所有者标识、显示名、绑定时间、有效或撤销状态。 | 单实例一名所有者。每台设备独立授权和撤销，审计保留当时的设备标识。 |
| 项目、工作区 | 项目标识、节点标识、允许访问的仓库。工作区标识、所属任务、节点、实际目录、固定的基准提交。 | 一个项目对应一个登记的节点和仓库。每个可写工作区仅归属一个任务。更换工作区保留历史关联。 |
| 任务 | 任务标识、项目、创建者、目标、范围、验收条件、固定基准、执行 Agent、主状态、返工轮数。 | 草稿允许缺项，提交时补齐。当前尝试、当前产物产生后绑定。终态重做记录来源任务标识。 |
| 尝试 | 尝试标识、任务标识、任务内序号、执行或复核角色、节点、工作区或只读输入、Agent、开始时间、执行结果及结束时间。 | 任务内序号唯一。未结束时结果待定，原生会话标识按能力记录。每条回执只更新所引用的尝试。 |
| 产物版本与证据 | 版本标识、所属任务和执行尝试、任务内版本号、基准提交、变更清单、验证记录、归档位置和内容校验值。 | 版本归属于一次执行尝试。证据定位到该版本内的具体记录。内容变更形成新版，已归档版本只读。 |
| 动作授权 | 请求标识、所属尝试、动作、目标工作区与输入版本、命令与参数摘要、允许范围、到期时间、状态。决定后追加决定、时间、设备或自动到期原因。 | 一个请求最多有一个生效决定。执行结果独立记录并关联该请求。参数有变、请求过期或尝试更换时必须换新请求。 |
| 复核与验收 | 复核记录含复核尝试、产物版本、结论及证据引用。验收记录含任务、版本、接受或退回、设备、时间，退回时必填理由。 | P2 仅采用该任务当前版本有效复核尝试的结论。验收时同时核对版本、复核和当前状态。对同一待办的冲突决定只生效一次。 |

## 6. 所有权、工作区与授权边界

**安装与找回。** 初次认领要求在安装主机以本机管理权限发起，将第一个桌面设备绑定为所有者设备后立即关闭初始入口。之后由可信设备为手机等设备签发单次限时配对请求。所有设备丢失时，从安装主机执行所有者恢复，撤销全部旧设备、存量会话和未用配对凭据，然后绑定新设备。恢复流程记录审计。干净实例导入旧备份后从安装主机重新绑定可信设备，历史决定保留原操作者。

**Git 基准与产物保护。** 首发只接受允许访问的仓库中可解析的 Git 提交。可从分支选择，但保存解析后的提交标识，并在派发前确认仍可读取。仓库没有提交时保留草稿。源工作区未提交的内容不随任务带入。若返工或恢复会覆盖未归档的改动，保留工作区，让所有者选择另建工作树或先手动整理。归档校验未通过时，不把索引条目或 Agent 文本当作差异文件。允许从仍可核验的原始内容恢复同版归档，内容变化则重新出具版本。

**验证证据。** 受管执行步骤记录用途、所针对版本、实际命令或步骤、退出结果和输出引用。未运行的测试标注“未运行”与原因。干运行标注“模拟执行”，列明验证范围和省略的真实动作。Agent 记述标注“Agent 自述”。只有适配器采集且与本版本对应的真实执行记录可列作实际测试结果。若验收条件明确需要某项实际测试，则模拟执行或自述均不足以通过该项复核。

**首项受管动作。** P1 要实际支持由所有者预登记的一次测试运行。请求绑定测试命令与参数摘要、目标工作区及待测内容的版本指纹、尝试和许可范围。启动前重验指纹，待测内容已变化时需要新请求。受控执行配置确保 Agent 无法从其他 Shell、脚本或工具路径绕过授权直接启动同一测试。缺少该能力的配置不能承接要求此保护的任务。节点保留启动记录和退出结果。

**授权与解除阻塞。** 等待期间显示动作、目标、参数摘要与有效期。拒绝或到期后，旧请求关闭并清除其“等待授权”原因，节点不得执行该请求。存在其他阻塞时分别保留。执行者可以跳过可选动作并记录影响，或提出新的受管方案。若必须由所有者选择后续处理，则转为“等待答复”，列出调整范围、重新申请或终止等实际可用选项。再次申请产生新请求，重新核验参数、尝试和授权。

## 7. 发布判断

P1 通过全部 P1 用例后进入内部试用。P2 按升级后的复核路径重跑 P1 用例并通过全部 P2 用例，每次演练记录任务、尝试、版本和实际结果。首发质量门槛与[产品需求文档第 6 节](01-prd.md#6-首发质量目标与验证方式)一致。

- **首次使用与手机验收。** 3 位目标用户中至少 2 位在约定环境内于 20 分钟内独立完成部署、配对和首次派单。3 位用户合计处理 10 项真实任务，每项仅计第一次进入待验收的版本，至少 8 项可在手机上说明版本、引用证据并决定接受或退回。另用缺少必需记录、引用旧版记录两份样本验证独立复核，两份均须被退回。
- **竞争与恢复。** 对授权或验收做 30 组双端并发决定，覆盖相反决定、重复点击和断线重发。每组仅一个生效决定。分别演练客户端掉线、控制服务重启、节点失联、进程丢失和动作结果未知。完成 A21 的干净实例恢复，并覆盖已撤权设备与只读复核越界测试。
- **发布阻断。** 错误接受产物版本、重复执行受管动作、复核越权写入，任一项出现即阻断发布。
